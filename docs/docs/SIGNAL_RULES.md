# Signal Rules

## Purpose

Signal rules define how this project presents meaning, authority, and value across pages, campaigns, captions, forms, and supporting assets.

They exist to prevent tone drift, message dilution, and inconsistent execution across tools, collaborators, and future revisions.

## Primary Signals

The project should consistently signal:

- Permanence
- Territory trust
- Craftsmanship
- Restraint
- Endurance
- Quiet confidence
- American handbuilt quality
- Rider-led discovery

## What the Site Should Feel Like

- Calm
- Assured
- Durable
- Field-tested
- Premium without posturing
- Editorial, not promotional
- Human, not automated
- Specific, not noisy

## Messaging Hierarchy

When in doubt, emphasize signals in this order:

1. Permanence
2. Territory authority
3. Handbuilt craftsmanship
4. Rider trust
5. Product fit
6. Technical detail

Technical detail supports belief, but should not dominate the emotional surface of the brand.

## Copy Signal Rules

### Prefer
- strong nouns
- short sentences
- measured confidence
- physical imagery
- tactile language
- terrain, weather, effort, and place
- craftsmanship language grounded in reality

### Avoid
- hype language
- startup tone
- trend language
- forced luxury language
- loud calls to action
- generic “premium brand” filler
- excessive claims without grounding
- artificial urgency

## Offer and CTA Rules

Calls to action should feel directional, not aggressive.

Preferred CTA behavior:
- invite discovery
- open a path
- clarify next action
- route to Ian cleanly
- support rider confidence

Avoid CTAs that feel:
- pushy
- manipulative
- overstated
- discount-driven
- urgency-driven

## Territory Signal Rules

Texas, Arkansas, and Oklahoma should feel like lived territory, not marketing placeholders.

Territory references should communicate:
- local familiarity
- trust
- presence
- route legitimacy
- real-world riding context

Do not present the territory as abstract market segmentation.

## Visual Signal Rules

Photography, layouts, and supporting assets should reinforce:

- texture
- terrain
- weather
- titanium permanence
- rider seriousness
- understated confidence

Avoid visuals that feel:
- over-designed
- trend-chasing
- artificially “luxury”
- noisy
- generic stock-performance marketing

## System Rule

If a future page, campaign, feature, or AI-generated output weakens the project’s core signals, rewrite it until it aligns.

Doctrine defines tone.
Territory authority defines routing.
Signal rules define presence.

All three must remain aligned.
